# Changelog

All notable project changes will be documented here.

## 0.1.1 - 2026-06-01

- Added the Windows Tauri desktop app for SAM3DBody.
- Added in-process Rust-to-C++ engine loading through the native C API.
- Added image and video workflows with 2D preview, 3D preview, hardware
  telemetry, model browsing, and export controls.
- Added OBJ/GLB mesh export, static image BVH export, and multi-person video
  BVH extraction.
- Added release packaging for installer, MSI, portable CUDA build, and runtime
  DLL pack.
- Added source release README, NOTICE, and upstream/model attribution.
