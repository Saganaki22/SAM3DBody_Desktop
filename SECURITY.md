# Security Policy

## Supported Versions

Only the latest tagged release is actively supported.

## Reporting A Vulnerability

Please report security issues privately through GitHub's security advisory flow
if it is enabled for the repository. If it is not enabled, open a minimal issue
that says a private security report is needed without posting exploit details.

## Release Verification

Release assets are large because they include CUDA, ONNX Runtime, OpenCV, ggml,
and native engine DLLs. Prefer assets attached to the official GitHub release
for this repository. Checksums may be published with release notes or as a
release asset.
